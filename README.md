## 🎯 Project Overview

My Study Planner is an interactive Flutter application designed to help students organize their subjects, manage study hours, and track their academic goals through a simple and user-friendly interface.

## ✨ Implemented Features

- Add new study goals.
- Display subjects and study hours.
- Mark study goals as completed.
- Delete unwanted study goals.
- Validate user input.
- Update the interface dynamically.
- Display completed goals with strikethrough text.
